# DJI Action5 Pro 视频归档工具

> ⚠️ **项目说明**：这是一个个人自用工具，日常维护和功能迭代集中在 `视频归类v2.1新ui.py` 版本。`自己选择版本.py` 因业务逻辑差异较大，后续会同步更新。如遇问题或需求，以 v2.1 版本为准。

一个基于 Python 的桌面工具，用于将 DJI Action5 Pro 相机拍摄的视频和延时摄影素材按拍摄日期自动归档。支持多源磁盘扫描、分块流式复制、实时进度显示、完整性校验和任务取消。

## 功能特性

- **双阶段归档**：先复制普通视频文件，再处理延时摄影文件夹，互不干扰
- **多源目录扫描**：同时扫描多个磁盘的 `DCIM\DJI_001` 和 `DCIM\TIMELAPSE` 目录
- **智能日期归档**：根据文件名中的拍摄日期，自动归类到 `年\月\日` 三层目录结构
- **跨日期延时摄影**：延时摄影文件夹通过文件修改时间自动匹配正确归档日期
- **分块流式复制**：以 4MB 为单位分块复制大文件，实时显示速度（MB/s）和单文件进度
- **原子写入**：先写入 `.tmp` 临时文件，完成后原子替换，中途失败不污染目标文件
- **完整性校验**：跳过已存在且大小一致的目标文件，断点续传友好
- **异常恢复**：单个文件复制失败不中断整体任务，错误日志完整记录
- **任务可取消**：随时中断，当前文件完成后停止，已写入文件自动清理
- **退出保护**：运行中关闭窗口会弹出确认对话框，防止误操作

## 归档规则

### 视频文件

DJI Action5 Pro 使用固定命名格式，程序通过正则 `^DJI_(\d{8})\d{6}_(\d{4})_[A-Z]` 识别：

```
DJI_20260914123000_0001_D.MP4
       ────────  ────
        拍摄日期   序号编号
```

匹配成功后归档到：

```
<目标根目录>\YYYY\MM\DD\原文件名
```

示例：`DJI_20260914123000_0001_D.MP4` → `G:\Osmo action5 pro\2026\09\14\DJI_20260914123000_0001_D.MP4`

支持的视频扩展名：`.mp4`、`.mov`、`.m4v`（不区分大小写）

### 延时摄影

延时摄影素材存放在 `TIMELAPSE` 目录下，每个素材是一个独立文件夹，命名格式为 `001_XXXX`（XXXX 对应同批次视频的序号编号）。

程序会先处理完普通视频，建立 `序号 → 目标日期目录` 的映射，再自动将延时摄影文件夹归入对应的日期目录。

## 使用方法

### 1. 安装依赖

```powershell
cd "大疆视频归类"
python -m pip install -r requirements.txt
```

### 2. 修改路径配置（v2.1 / v2.0）

打开源代码，修改顶部的路径常量：

```python
# 多个磁盘的普通视频源目录
SOURCE_DIRS = [
    r"E:\DCIM\DJI_001",
    r"F:\DCIM\DJI_001"
]

# 多个磁盘的延时摄影源目录
TIMELAPSE_SOURCE_DIRS = [
    r"E:\DCIM\TIMELAPSE",
    r"F:\DCIM\TIMELAPSE"
]

# 统一归档根目录
TARGET_ROOT = r"G:\Osmo action5 pro"
```

### 3. 运行

```powershell
python "视频归类v2.1新ui.py"
```

如果使用**选择版**，路径可在界面中通过文件对话框选择，无需修改代码。

## 安全设计

| 设计 | 说明 |
|------|------|
| 临时文件写入 | 目标文件先写为 `.tmp`，完成后 `os.replace` 原子替换，避免中途异常导致文件损坏 |
| 退出确认 | 任务运行中关闭窗口会弹窗询问，避免误触 |
| 取消机制 | 子线程通过 `threading.Event` 实现协作式取消，确保资源正确释放 |
| 完整性校验 | 复制前比对源/目标文件大小，相同则跳过 |
| 异常隔离 | 单个文件失败不影响其他文件继续处理，最终汇总失败数量 |
| 路径安全 | 使用 `os.makedirs(..., exist_ok=True)` 自动创建归档目录，不会覆盖已有同名目录 |
